# Change log 22102026

## Fix worker startup crash from oversized Oracle ERROR_MESSAGE

### Objective
Fix `ORA-12899` causing `AeroSyncWorker` to exit during startup. The worker log showed `StoredErrorMessageLocalizationMigration` translating a legacy `FILE_RECORDS.ERROR_MESSAGE` into 2,013 UTF-8 bytes for an Oracle column limited to 2,000 bytes.

### Files changed
- `aerosync-worker/src/main/java/vatm/aerosync/worker/service/VietnameseStoredErrorMessage.java`
- `aerosync-worker/src/main/java/vatm/aerosync/worker/service/StoredErrorMessageLocalizationMigration.java`
- `aerosync-worker/src/main/java/vatm/aerosync/worker/pipeline/FileProcessingPipeline.java`
- `aerosync-worker/src/main/java/vatm/aerosync/worker/service/PermitImportCoordinator.java`
- `aerosync-worker/src/test/java/vatm/aerosync/worker/service/StoredErrorMessageLocalizationMigrationTest.java`
- `aerosync-worker/src/test/java/vatm/aerosync/worker/service/VietnameseStoredErrorMessageTest.java`

### Before and after
- Before: string truncation counted Java characters, not UTF-8 bytes. Vietnamese error messages could exceed Oracle `VARCHAR2(2000 BYTE)` and abort the migration runner.
- After: persisted and migrated error messages are capped at 2,000 UTF-8 bytes without splitting a Unicode code point. Existing oversized translated rows are also capped on migration.

### Verification
- Worker log at `C:\AeroSync\logs\worker\AeroSyncWorker.out.log.old` showed the exact ORA-12899 error (actual 2,013 bytes; maximum 2,000).
- `mvnw.cmd -f pom.xml -pl aerosync-worker -am clean test -Dtest=StoredErrorMessageLocalizationMigrationTest,VietnameseStoredErrorMessageTest -Dsurefire.failIfNoSpecifiedTests=false`: BUILD SUCCESS; 7 tests; 0 failures/errors.
- `git diff --check`: passed.
- No direct Oracle update, replay, service restart, or deployment was performed by this change.

### Remaining
The installed worker is still the 19/10/2026 build and needs deployment of a newly built worker before the runtime fix takes effect. Use an Administrator maintenance window; do not replay old email/file jobs automatically.
